# Changelog

## v0.2.0 (28 de octubre de 2025)
- ✨ **Nuevas escalas de temperatura**: Añadidas 5 escalas adicionales
  - Rankine (°R) - Escala absoluta basada en Fahrenheit
  - Réaumur (°Ré) - Escala histórica europea
  - Delisle (°De) - Escala invertida histórica
  - Newton (°N) - Escala de Isaac Newton
  - Rømer (°Rø) - Escala danesa histórica
- 📸 Captura de pantalla añadida a la documentación
- 📝 README mejorado con información completa del proyecto
- 📖 Guía de uso actualizada con todas las escalas
- 🔧 Fórmulas de conversión implementadas para todas las escalas

## v0.1.0
- 🎉 Creación del proyecto Angular con CLI 18.2.21
- 🧮 Implementación de `TemperatureService` con Kelvin como base
- 🎨 `ConverterComponent` con formulario reactivo y validación
- 💅 Estilos de tarjeta y botón, comportamiento dinámico
- ✅ Pruebas unitarias básicas con Jasmine/Karma
- 📚 Documentación completa en español (`docs/`)
- 🌡️ Soporte inicial para Celsius, Fahrenheit y Kelvin
