# Documentación del despliegue en GitHub

## 1) Introducción
- Este documento detalla el proceso de subir el proyecto a GitHub y desplegarlo en GitHub Pages. El objetivo es hacer que la aplicación esté accesible públicamente en una URL como `https://maximofernandezriera.github.io/conversor-temperatura/`.
- **Pasos clave**: Inicialización de Git, subida de archivos, configuración de GitHub Pages.
- **Requisitos**: Cuenta en GitHub, token de acceso si es necesario (pero usaremos comandos estándar).

## 2) Comandos ejecutados
- `git init`: Inicializa el repositorio Git local.
- `git add .`: Añade todos los archivos al staging area.
- `git commit`: Crea un commit con los cambios.
- `git remote add origin`: Configura el remoto de GitHub.
- `git push`: Sube el código a GitHub.
- Configuración de GitHub Pages: Selecciona la rama `gh-pages` o el directorio raíz.

## 3) Pasos detallados
- **Paso 1**: Inicializar Git (hecho).
- **Paso 2**: Añadir y commitear archivos.
- **Paso 3**: Configurar el remoto y push a GitHub.
- **Paso 4**: Desplegar en GitHub Pages (requiere acceso web a GitHub).

## 4) Posibles errores y soluciones
- Si falla el push, verifica credenciales de GitHub.
- Asegúrate de que el repositorio esté creado en GitHub antes de push.
