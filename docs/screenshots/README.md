# Screenshots

Esta carpeta contiene las capturas de pantalla de la aplicación.

## Capturas requeridas:

1. **vista-principal.png** - Vista inicial de la aplicación
2. **celsius-fahrenheit.png** - Conversión de 25°C a Fahrenheit
3. **fahrenheit-celsius.png** - Conversión de 100°F a Celsius
4. **validacion.png** - Validación de errores/campos
5. **responsive.png** - Vista en modo responsive (móvil/tablet)

## Cómo tomar las capturas:

1. Abre la aplicación en http://localhost:4200/
2. Para cada caso, realiza la acción correspondiente
3. Guarda las capturas con los nombres indicados en esta carpeta
